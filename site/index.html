为什么需要独立增强版

直击 Remote-SSH 代理的三大真实痛点

在原有代理方案基础上全面重构，专为高并发、长连接与 Antigravity v2.6.0+ 打造。

🛡️

根治 FakeDNS UDP 句柄泄漏

传统 FakeDNS 模式长期运行易产生大量 UDP :0 套接字泄漏，耗尽临时端口并拖垮 SSH。默认启用 mgraftcp-no-fakedns，并提供无 Root Crontab FD Guard 兜底。

🔄

v2.6.0+ agy 与旧版无缝兼容

自动包装 ~/.gemini/bin/agy（--version 零延迟直通、原子保留 agy.bak），同时兼容旧版 language_server_linux_* 及历史包装脚本无感升级。

⚡

SSH 保活与 9 项一键排错

自动写入 ServerAliveInterval 30 清理僵尸隧道；状态面板集成 9 项端到端诊断，支持精准清理 PPID=1 孤儿进程并自动切换可用协议。

3 分钟快速开始

三步完成安装与配置

无需在远程服务器上安装 root 依赖，本地和远程均开箱即用。

01

安装扩展并启动本地窗口

在 Antigravity IDE 扩展市场搜索 EmorZz1G.antigravity-agy-proxy 安装。先启动本地 Clash / V2Ray（默认端口 7890），再打开一个本地窗口，等待左下角 AGY Proxy 变绿。

02

以新窗口连接远程服务器

从本地窗口选择 Connect SSH Host in New Window 连接远端主机。扩展会自动配置 ~/.ssh/config.antigravity 反向端口转发，并包装远程 agy / language_server。

03

面板调优与一键排错

点击左下角 AGY Proxy 打开统一面板：随时切换 http / socks5 / socks5h、调整拦截模式、查看流量监控、开关 Crontab FD Guard，或运行 9 项诊断与 Auto Fix。

按环境选择最佳策略

三种代理拦截模式对比

支持在状态面板或设置项 antigravity-agy-proxy.proxyMode 中随时切换。

默认 · 推荐

mgraftcp-no-fakedns

TCP ptrace 透明拦截（禁用 FakeDNS）+ 标准代理环境变量

  • 接管不读取环境变量的子进程
  • 彻底消除 FakeDNS UDP :0 句柄泄漏
  • 搭配 http 或 socks5h 稳定性最佳
零 ptrace 开销

env-only

纯环境变量注入（HTTP_PROXY / HTTPS_PROXY / ALL_PROXY）

  • 无 ptrace 性能开销，无 UDP 风险
  • 兼容限制 ptrace 的 Docker / 容器环境
  • 推荐配合 http 或 socks5h 使用
DNS 污染专用

mgraftcp-fakedns

TCP ptrace + libdnsredir FakeDNS + GODEBUG=netdns=cgo

  • 解决远端本地 DNS 污染导致的证书错误
  • 仅建议在直连解析失败时开启
  • 建议同时开启 Crontab FD Guard 防护
